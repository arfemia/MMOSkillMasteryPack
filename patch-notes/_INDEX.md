# Patch notes - MMO Skill Mastery Pack

Per-version public release notes (newest first). Same paradigm as the main mod repo: YAML frontmatter (`version`/`type: patch-note`/`status`), user-facing voice, no em-dashes. `CURSEFORGE.md` is the public listing; keep its Versions table in sync.

- [[2.0.0]] - draft: every mastery file moves onto the plugin's structured schema (PascalCase codec files, `Parent` bases, per-skill families written by generators); track content unchanged in play.
- [[1.4.0]] - draft: seven damage-school mastery tracks (Fire, Ice, Lightning, Water, Arcane, Void, Poison), ten nodes each, gated on combat level.
- [[1.1.2]] - draft: Piercing Shot pierce node now grants its extra targets, its damage nodes no longer double-apply, and Magic/Artillery mastery bonuses reach weapon swings.
- [[1.1.1]] - released: restores the Mastery Point level rewards (template id mismatch meant no skill offered them).
- [[1.1.0]] - released: full 9-language localization, Mastery Infusion offer fix, localized reward lines.
