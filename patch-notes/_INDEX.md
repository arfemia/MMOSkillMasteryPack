# Patch notes - MMO Skill Mastery Pack

Per-version public release notes (newest first). Same paradigm as the main mod repo: YAML frontmatter (`version`/`type: patch-note`/`status`), user-facing voice, no em-dashes. `CURSEFORGE.md` is the public listing; keep its Versions table in sync.

- [[2.0.1]] - held (requires plugin 1.6.1 + CommonLib 2.1.0): a picture for every damage-school track and every quest, A Word with the Trainer collected at the trainer alone, the two level climbs hiding their report-back step until the climbing is done, the Mastery Tithe on the shared quest schema, the repeating quests badged off their own timing, and the Mastery Trainer's environmental immunity authored the way the engine reads it.
- [[2.0.0]] - seven damage-school mastery tracks, a Mastery Trainer who talks and keeps a daily, every mastery file rewritten onto the plugin's structured schema, and the Piercing Shot / Magic / Artillery fixes. Folds in the unreleased 1.1.2, 1.2.0 and 1.4.0 work, so it is the one note covering everything since 1.1.1.
- [[1.1.1]] - released: restores the Mastery Point level rewards (template id mismatch meant no skill offered them).
- [[1.1.0]] - released: full 9-language localization, Mastery Infusion offer fix, localized reward lines.
