A small release with no code. `manifest.json` changes only its `Version`, to `2.2.1`: `ServerVersion` stays `>=0.7.0-pre.0 <0.8.0` and the dependencies stay `Ziggfreed:MMOSkillTree ^1.7.1` and `Ziggfreed:ZiggfreedCommon >=2.3.0`. No shipped id changes.

- **Changed: the Mastery Trainer's questline is main quests.** Five of the pack's nine quests under `Server/ZiggfreedCommon/Quests/MMOSkillTree/Mastery/` write `Listing.MainLine` true, ZiggfreedCommon 2.4.0's leaf, so a quest list shows them first with the star and the gold bar: `meet_the_mastery_trainer`, `pack_first_milestone`, `pack_essence_collector`, `pack_path_of_mastery` and `pack_essence_devotee`. The other four write none: the daily `mastery_tribute`, the weekly `mastery_lesson_week`, `mastery_tithe_credit` and the retired `pack_mastery_tithe`. On ZiggfreedCommon 2.3.0, which the manifest floor still admits, the leaf is unread and the quests list as before.
